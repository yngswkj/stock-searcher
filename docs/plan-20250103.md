# 個人資産拡大のための「Multibagger Hunter (日米対応版)」実装計画書

## 1. プロジェクト概要
### 1.1 目的
本プロジェクトは、学術論文 *"The Alchemy of Multibagger Stocks (2025)"* の知見に基づき、将来的に株価が10倍以上（マルチバガー）となる可能性を秘めた「米国株」および「日本株」を自動抽出するWebアプリケーションを構築するものである。

### 1.2 目標
- **維持コストゼロ**: サーバー代を一切かけない。
- **完全自動化**: 銘柄データの収集・計算・更新を自動で行う。
- **日米対応**: 米国市場（S&P600等）と日本市場（グロース/スタンダード）を横断して検索可能にする。

## 2. 抽出ロジック（論文に基づく基準）
以下の4つの要素を満たす銘柄を抽出対象とする。

1.  **Size (小型株)**: 巨大企業よりも成長余地の大きい小型株。
    - *基準*: 時価総額 20億ドル（約3,000億円）未満 ※調整可能
2.  **Value (割安)**: 本来の価値より安く放置されている。
    - *基準*: 低PER、低PBRなど。
3.  **Quality (高収益)**: すでに「稼ぐ力」がある。
    - *基準*: 高ROE (10%以上推奨)。
4.  **Cash Flow (現金創出力)**: 最重要指標。
    - *基準*: 高いフリーキャッシュフロー(FCF)利回り（3〜5%以上）。

## 3. システムアーキテクチャ (Jamstack構成)

バックエンドサーバーを持たず、GitHub Actionsでデータを生成し、静的サイトとして配信する。

### 3.1 構成要素
1.  **データソース**: 
    - 米国株: `yfinance` API
    - 日本株: JPX公式サイト (Excel) + `yfinance` API (`xxxx.T`)
2.  **バッチ処理 (ETL)**: `GitHub Actions`
    - 定期実行 (Cron) でPythonスクリプトを駆動。
    - データ取得 → 指標計算 → JSON生成。
3.  **データストア**: `public/stock_data.json`
    - リポジトリ内に生成される静的JSONファイル。
4.  **フロントエンド**: `GitHub Pages` or `Vercel`
    - Vue.js (CDN版) + Tailwind CSS。
    - ブラウザ上でJSONを読み込み、高速にフィルタリング。

### Step 2: データ収集スクリプト (`scripts/fetch_data.py`)

日本株リストの取得と、通貨単位の統一処理を実装する。

```python
import yfinance as yf
import pandas as pd
import json
import time

# --- 設定 ---
# 米国株: 本来はS&P600等の全リストを使うが、ここではデモ用リスト
US_TICKERS = ["RUM", "IONQ", "HIMS", "PLTR", "SOFI", "APPS", "CROX"]

# 日本株: 取得したい市場区分
TARGET_JP_MARKETS = ['グロース', 'スタンダード']

def get_jpx_tickers():
    """JPXから日本株全銘柄を取得し、対象市場のティッカー(.T)を返す"""
    print("Fetching JPX ticker list...")
    try:
        url = "[https://www.jpx.co.jp/markets/statistics-equities/misc/tvdivq0000001vg2-att/data_j.xls](https://www.jpx.co.jp/markets/statistics-equities/misc/tvdivq0000001vg2-att/data_j.xls)"
        df = pd.read_excel(url)
        # 対象市場でフィルタ
        mask = df['市場・商品区分'].apply(lambda x: any(m in x for m in TARGET_JP_MARKETS))
        tickers = df[mask]['コード'].astype(str) + ".T"
        return tickers.tolist()
    except Exception as e:
        print(f"Error fetching JPX: {e}")
        return []

def main():
    data_list = []
    
    # 1. リスト作成 (デモ用に日本株は先頭50件に制限)
    jp_tickers = get_jpx_tickers()[:50] 
    all_tickers = US_TICKERS + jp_tickers
    
    print(f"Processing {len(all_tickers)} tickers...")

    for symbol in all_tickers:
        try:
            ticker = yf.Ticker(symbol)
            info = ticker.info
            
            market_cap = info.get('marketCap')
            
            # 必須データのチェック
            if market_cap:
                # 通貨判定と単位変換
                currency = info.get('currency', 'USD')
                is_jp = currency == 'JPY'
                
                # フィルタ用: ドル換算の時価総額 (1ドル=150円換算)
                if is_jp:
                    mcap_sort_usd = market_cap / 150_000_000_000 # Billion USD
                    mcap_display = round(market_cap / 100_000_000, 2) # 億円
                else:
                    mcap_sort_usd = market_cap / 1_000_000_000 # Billion USD
                    mcap_display = round(market_cap / 1_000_000_000, 2) # Billion USD

                # FCF利回り計算
                fcf = info.get('freeCashflow')
                fcf_yield = round((fcf / market_cap) * 100, 2) if fcf else 0
                
                # ROE
                roe = round(info.get('returnOnEquity', 0) * 100, 2) if info.get('returnOnEquity') else 0

                data_list.append({
                    "ticker": symbol,
                    "name": info.get('shortName', symbol),
                    "country": "JP" if is_jp else "US",
                    "price": info.get('currentPrice'),
                    "mcap_display": mcap_display,      # 表示用数値 (単位は国による)
                    "mcap_sort": mcap_sort_usd,        # フィルタ用数値 (USD統一)
                    "fcf_yield": fcf_yield,
                    "roe": roe,
                    "pe": info.get('trailingPE', 0)
                })
                
            print(f"Fetched: {symbol}")
            time.sleep(1.5) # API制限回避のため待機時間を確保
            
        except Exception as e:
            print(f"Error {symbol}: {e}")

    # JSON出力
    with open("public/stock_data.json", "w", encoding='utf-8') as f:
        json.dump(data_list, f, indent=2, ensure_ascii=False)

if __name__ == "__main__":
    main()

```

### Step 3: 自動化設定 (`.github/workflows/update.yml`)

毎日深夜に実行し、結果をリポジトリにプッシュする。

```yaml
name: Update Stock Data
on:
  schedule:
    - cron: '0 0 * * *' # 毎日 AM0:00 (UTC)
  workflow_dispatch:

permissions:
  contents: write # リポジトリへの書き込み権限を付与

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.9'
      - name: Install Dependencies
        run: pip install -r requirements.txt
      - name: Run Script
        run: |
          mkdir -p public
          python scripts/fetch_data.py
      - name: Commit & Push
        run: |
          git config --global user.name 'GitHub Action'
          git config --global user.email 'action@github.com'
          git add public/stock_data.json
          git diff --quiet && git diff --staged --quiet || git commit -m "Update stock data"
          git push

```

## 6. デプロイ手順

1. **リポジトリ作成**: GitHubで新規リポジトリを作成。
2. **ファイル配置**: 上記ディレクトリ構造通りにファイルを配置・コミット。
3. **権限設定**: リポジトリ設定 `Settings` > `Actions` > `General` > `Workflow permissions` を **Read and write permissions** に変更（超重要）。
4. **Pages公開**: `Settings` > `Pages` > `Source` を `main` ブランチの `/ (root)` に設定。
5. **完了**: 翌日（またはActionsを手動実行後）、指定のURLでアプリが稼働する。
